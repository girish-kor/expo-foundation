## [ STRUCTURE ]

```text
.
├── index.js
├── app.json
├── babel.config.js
├── metro.config.js
├── tailwind.config.js
├── eslint.config.js
└── src/
    ├── App.jsx
    ├── global.css
    ├── navigation/
    └── screens/
```

---

## [ RUNTIME ]

| File          | Responsibility                                                       |
| ------------- | -------------------------------------------------------------------- |
| `index.js`    | Registers the root component from `src/App.jsx`.                     |
| `src/App.jsx` | Imports `src/global.css`.                                            |
| `App`         | Mounts gesture root, safe-area provider, navigation, and status bar. |

---

## [ NAVIGATION ]

```text
Root
└── Bottom Tab Navigator
    └── Home
        └── Native Stack Navigator
            ├── HomeMain
            └── HomeScreen
```

- Root: bottom tab navigator.
- Tab: Home.
- Home renders native stack navigator.
- Stack: `HomeMain -> HomeScreen`.
- Headers hidden for tab and stack.

---

## [ STYLING ]

- `src/global.css` imports base, component, and utility layers.
- Components apply utility class names.
- Bundler input: `./src/global.css`.
- Content scan: `./src/**/*.{js,jsx}`.

---

## [ CONFIGURATION ]

| File                 | Purpose                                                                                     |
| -------------------- | ------------------------------------------------------------------------------------------- |
| `app.json`           | Portrait, light UI, tablet support, platform icon assets, Android package, web favicon.     |
| `babel.config.js`    | Caches config; sets JSX import source and styling preset.                                   |
| `metro.config.js`    | Wraps default with styling input `./src/global.css`.                                        |
| `tailwind.config.js` | Scans `./src/**/*.{js,jsx}`, uses styling preset, empty extended theme, no plugins.         |
| `eslint.config.js`   | Extends flat config; ignores `dist/**`, `node_modules/**`, `.expo/*`, `android/*`, `ios/*`. |

---

## [ COMMANDS ]

| Command            | Action                          |
| ------------------ | ------------------------------- |
| `npm run start`    | Start development server        |
| `npm run android`  | Build and run Android target    |
| `npm run prebuild` | Generate Android native project |
| `npm run lint`     | Run lint checks                 |
| `npm run lint:fix` | Run lint checks and apply fixes |

---

## [ MAINTENANCE ]

- Add screens under `src/screens`.
- Register stack routes in `src/navigation`.
- Add tab routes in the tab navigator.
- Keep utility class usage under `src`; scan covers only `src/**/*.{js,jsx}`.
- Native directories are generated by prebuild and excluded from lint.
